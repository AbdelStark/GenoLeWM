# Implementation Tracker — 2026-05-20

Generated from the spec corpus committed on branch
`spec/bootstrap-2026-05-20`. This document is the dashboard maintainers
use to see the state of v0.1 implementation work. The issue list below
is populated as the corresponding GitHub issues are filed by the
spec-bootstrap turn (Phase 2 of the bootstrap goal).

Each implementation issue:

- Cross-links to a spec section or an RFC.
- Lives at exactly one milestone (`v0.1`, `v0.2`, `v0.3`, `v0.4`).
- Carries exactly one type, area, priority, and effort label, plus one
  or more `spec:rfc-NNNN` labels.

The file is regenerated by the maintenance script under
`tools/tracker/regenerate.py` (planned). Until that script lands, the
file is maintained by hand at each release boundary.
